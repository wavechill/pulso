Componentes do Pulso Windows

Python embutido 3.14.7, distribuição oficial PSF para Windows x64.
https://www.python.org/downloads/release/python-3147/
A licença acompanha runtime/python/LICENSE.txt. As licenças e metadados das bibliotecas Python acompanham runtime/python/packages.

FFmpeg e ffprobe, distribuição LGPL compartilhada para Windows x64, sem modificações.
https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-11-20-12-40
Código da versão 660b5aa7db:
https://github.com/FFmpeg/FFmpeg/archive/660b5aa7db.tar.gz
Receita de compilação e fontes das dependências:
https://github.com/FFmpeg-Builds/FFmpeg-Builds/tree/autobuild-2026-11-20-12-40
A saída de runtime/media/ffmpeg.exe -buildconf identifica as opções do binário.

O Pulso usa o Deno v2.9.7 e o yt-dlp v2026.10.26 para importação de links.
https://github.com/denoland/deno/releases/tag/v2.9.7
https://github.com/yt-dlp/yt-dlp/tree/2026.10.26

WebView2 SDK 1.0.4258.31 e Microsoft Edge WebView2 Fixed Version Runtime 158.0.4370.33 x64, distribuído na pasta runtime/webview2. A janela também pode usar o Evergreen instalado. O pacote de runtime vem da Microsoft.
https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31
https://developer.microsoft.com/microsoft-edge/webview2/

Modelo Basic Pitch do Spotify e fonte Barlow. Licenças em app/models/basic-pitch e app/web/fonts.
YAMNet, dos autores do TensorFlow, reconhece famílias de instrumentos. Conversão ONNX do projeto audiojs. A licença Apache 2.0 e a documentação da conversão estão em app/models/yamnet.
Mapa de guitarra de Wagsii para Chop Suey! e som de explosão de Guitar Flash 3. O aplicativo busca esses recursos nas fontes originais e guarda uma cópia no perfil do jogador.
https://www.enchor.us/?hash=7229be4a1730a8077687ff088e5547ef
https://guitarflash3.com/data/game/audio/explosao.wav
Separação instrumental com os quatro modelos Open-Unmix UMX-HQ. Pesos originais publicados pelos autores em https://zenodo.org/records/3370489. A licença e as assinaturas dos modelos distribuídos estão em app/models/umxhq.
